This is an example file to show you what to name your announcer files.

For player #5 (Gregory), you would:
1. Record an audio file saying something like "Number 5, Gregory!"
2. Save it as an MP3 file named: player_5.mp3
3. Place it in this announcers folder

The system will automatically play this announcement before Gregory's walkout song when the announcer is enabled.

Delete this text file after you understand the naming convention.
